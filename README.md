# InstantCapture
Cette application Android a été conçue pour les photographes de concert, de spectacle, de sport ou d'événementiel.

Avant une séance, l'utilisateur crée un fichier texte (par exemple Concert - Les Insus.txt).

Pendant la prise de vue, un simple appui sur le bouton rouge enregistre automatiquement la date et l'heure. Il est également possible d'ajouter un commentaire.

Tous les événements sont ajoutés à la suite dans le même fichier texte.

Exemple :

Concert : Les Insus

20:58:12 - Début du concert
21:15:47 - Solo guitare
21:48:03 - Changement de chanteur
22:34:19 - Fin du concert

Lors du tri des photos dans Lightroom, Photo Mechanic ou tout autre logiciel, il suffit de comparer l'heure de prise de vue des images avec le journal des événements pour retrouver instantanément les moments importants.

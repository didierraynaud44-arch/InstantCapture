# 📸 InstantCapture

**InstantCapture** est une application Android destinée aux photographes permettant d'enregistrer rapidement des événements horodatés pendant une séance photo.

Elle facilite le repérage des moments importants lors du tri des images dans Lightroom, Photo Mechanic, DxO PhotoLab ou tout autre logiciel de catalogage.

---

## ✨ Fonctionnalités

- 📄 Création d'un fichier texte pour chaque reportage.
- ⏱️ Enregistrement automatique de la date et de l'heure.
- 📝 Ajout d'un commentaire pour chaque capture.
- ➕ Les événements sont ajoutés automatiquement à la suite dans le même fichier.
- 📂 Les fichiers texte sont facilement récupérables depuis le téléphone.
- 🎯 Interface simple, pensée pour être utilisée rapidement sur le terrain.

---

## 📱 Exemple d'utilisation

### Avant le reportage

Créer un nouveau fichier :

```
Concert_Iron_Maiden.txt
```

### Pendant le reportage

À chaque moment important, appuyer sur le bouton **CAPTURER**.

Il est possible d'ajouter un commentaire :

- Début du concert
- Arrivée du chanteur
- Solo guitare
- Effets pyrotechniques
- Rappel
- Fin du concert

Chaque appui ajoute automatiquement un nouvel enregistrement.

Exemple :

```
25/07/2026 20:58:12
Début du concert

25/07/2026 21:14:45
Solo guitare

25/07/2026 21:48:07
Feux d'artifice

25/07/2026 22:36:18
Fin du concert
```

---

## 📷 Pourquoi cette application ?

Lors du tri des photographies, il suffit de comparer l'heure de prise de vue des images avec les heures enregistrées dans le fichier texte.

On retrouve immédiatement les moments importants du reportage sans avoir besoin de mémoriser la chronologie de l'événement.

Cette méthode est particulièrement utile pour :

- concerts
- festivals
- spectacles
- conférences
- manifestations
- compétitions sportives
- mariages
- reportages événementiels
